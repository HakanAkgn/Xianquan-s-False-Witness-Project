# False Witness research workspace

Research extensions for **False Witnesses: When Irrelevant Facts Change Transformer Answers**.

The repository was empty when this work began. The original authors' source repository and checkpoints have not been located. Any independently reconstructed experiments must be labeled as such, with their source assumptions, controls, raw outputs, and validation results recorded.

Work is developed on a separate research branch for review rather than silently replacing original results. No original manuscript or author checkpoints are included.
