## Settings recovered from manuscript passages

* f and g are independent uniform random functions [N]->[N]; x is uniform. N=8. One-step target f(x), two-step target g(f(x)). Suggestion names the intermediate company, not the output country.
* Suggestions occur in half of examples; when present, h=f(x) with probability 3/4, otherwise uniform over alternatives. Labels always use the true tables.
* Two pre-normalized layers, width 64, four heads, feed-forward width 128, exact GELU, zero dropout. Token embeddings and learned absolute positional embeddings; position initialization normal with standard deviation 0.02.
* 19 tokens and vocabulary size 12 for N=8; 0..7 values, 8 absent suggestion, 9 unused, 10/11 one-/two-step. Company-first order. Suggestion-last suffix (x,t,h); without suggestion (a,t,x). Final LayerNorm and eight-class linear readout at the last position.
* Float32 AdamW, learning rate .003, weight decay .01, betas (.9,.999), epsilon 1e-8, batch 128, gradient norm clipping 1.
* User-provided Figure 1 caption: eight models, 2,000 updates, 4,096 pairs/model, 27.4%->54.8%. These figures are original reported values, NOT the new implementation's results.

## Explicit reconstruction choices not verified in upstream code

1. Equal probability of one- and two-step tasks. This frequency was not recovered.
2. Standard causal lower-triangular self-attention at every layer. Direction-dependent access in the retrieved text supports causality, but the full mask specification was not recovered.
3. PyTorch default initialization for token embeddings, linear layers and LayerNorm; biases enabled. Only the positional initialization was recovered.
4. Cross entropy on the final true class only, with no auxiliary loss or scheduler. Full original objective code was unavailable.
5. Fresh on-the-fly draws with explicit CPU random generators; PyTorch deterministic algorithms; fixed seeds 11,29,47. These are not asserted to be original paper seeds.
6. Rejection-free, explicitly conditioned paired evaluation. The paper's exact conditional sampler was unavailable; distributions can differ even though all required semantic invariants hold.
7. The typed task introduces a second person-company relation, an extra query-relation token, a 28-token sequence and vocabulary size 14. It uses fixed query positions even when a suggestion is absent. It requires newly trained models and is not a checkpoint-compatible reproduction.

Do not compare the new numerical percentages with the original caption as a verified replication discrepancy. The architecture and core task are reconstructed; exact implementation parity is unresolved. Three new training seeds are a pilot and do not replicate the original eight-model estimate.

## Artifact discipline

All seeds and requested checkpoints are retained, including nulls, failures and lower-competence typed models. The repository retains compact event-level decisions for the three token-balanced 2,000-update comparisons, plus all summary tables and contingency counts. Event codes distinguish correct, suggested-wrong and other answers; they do not retain the identity of other answers. The decoder is `fw.evaluate.unpack_outcomes`. Full categorical outcomes (losslessly compressed JSON), per-example probabilities/margins and checkpoints are generated by the commands and included in the downloadable execution archive, not in the lightweight Git repository. The source/result manifest gives SHA-256 digests of execution artifacts. It is a content-integrity record, not a timestamping service or proof of external preregistration.

Within-seed paired intervals reflect finite test examples. Across-seed summaries treat the model seed as the independent unit. With three seeds, model-to-model confidence intervals are wide; 4,096 examples do not create 4,096 independently trained models.

## Outcome-field convention

In paired and cube outputs, rate fields named `following`, `control_rate`, `witness_rate`, or `incorrect_suggestion_following` track the designated incorrect country from the original wrong-hint construction. Under absent/correct-hint controls they are that same counterfactual wrong-answer rate, not following an actually supplied wrong suggestion. Accuracy fields always compare with the true answer.
